# Learning Clipper

一个用于收集网页选中文字的 Chrome 扩展。首个里程碑：v0.1（扩展版本 0.1.0）。

## 当前功能

- 获取当前网页中选中的文字。
- 保存到 Chrome 本地存储。
- 展示历史收藏，关闭弹窗后重新打开仍可读取。

## 安装与使用

1. 下载或克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
4. 在普通网页中选中文字，打开 Learning Clipper，点击「保存到收集箱」。
5. 重新打开扩展，查看历史收藏。

修改代码后，在扩展管理页点击刷新即可加载更新。

## 文件说明

- `manifest.json`：Manifest V3 配置、版本及权限。
- `popup.html`：弹窗页面。
- `popup.js`：获取选中文字、保存和展示收藏。
- `style.css`、`background.js`：预留空文件，当前未启用。

## 权限与数据

`activeTab` 和 `scripting` 用于读取用户当前网页的选中文字；`storage` 用于保存收藏。当前代码使用 `chrome.storage.local`，未实现服务器上传或跨设备同步。

## 已知限制

- Chrome 内部页面等受限制页面无法读取选中文字，目前没有友好的失败提示。
- 尚未阻止保存空内容或重复内容。
- 暂不支持删除、来源网址、网页标题或导出。

## 手动验证

在普通网页分别收藏两段文字，确认两条记录都显示；关闭并重新打开弹窗，确认记录仍在。
